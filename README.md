# 🎯 Quiz App

A simple **Quiz App** built using **HTML, CSS, and JavaScript**. It displays multiple-choice questions, checks the selected answer, highlights correct and wrong answers, and keeps track of the score.

🌐 [**Live Demo**](https://sunny1901kumar-sys.github.io/Quiz-App/)

![Quiz App Screenshot](https://github.com/sunny1901kumar-sys/Quiz-App/raw/main/Screenshot.png)

## ✨ Features

- 📝 Displays multiple-choice questions
- 🔘 Creates answer buttons dynamically
- ✅ Highlights the correct answer
- ❌ Highlights the wrong answer
- 🏆 Tracks the user's score
- ⏭️ Automatically moves to the next question
- 🎯 Displays the final score after completing the quiz
- ⛔ Prevents further questions after the quiz ends

## 🛠️ Technologies Used

- **HTML** – Structure
- **CSS** – Styling and layout
- **JavaScript** – Quiz logic, DOM manipulation, event handling, and score tracking

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
